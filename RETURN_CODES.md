# Salud Visual - EXE Return Codes

This document describes the exit code values for Salud Visual installers.

## Installer (`InstalarSaludVisual.exe`)

- `0`: Success
- `1`: Generic error
- `2`: Payload not found

## Uninstaller (`DesinstalarSaludVisual.exe`)

- `0`: Success
- `1`: Generic error

## Silent commands

- Install: `InstalarSaludVisual.exe /silent`
- Uninstall: `DesinstalarSaludVisual.exe /silent`
